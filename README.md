# World English Bible

The complete World English Bible (WEB) — all 66 books — free to read, search, and share.

Read it in the browser, add it to your phone's home screen and it works offline, listen to any chapter read aloud, or download the whole Bible as an ebook. Save verses with bookmarks, highlights, and notes, start the day with the Verse of the Day, and pass the Bible on with the built-in QR code.

**Live:** https://jesuslovestyler.github.io/World-English-Bible/ — also linked from https://jesuslovestyler.com/

The World English Bible is in the public domain. It was translated by Michael Paul Johnson and many volunteers.
